# Sefa Kapısız — Portfolio

Personal portfolio website built with React + Vite.

## Deploy to Vercel (3 steps)

### Option A — Vercel CLI (fastest)
```bash
npm install -g vercel
cd portfolio
npm install
vercel
```
Follow the prompts — it auto-detects Vite. Your site is live in ~60 seconds.

### Option B — GitHub + Vercel Dashboard
1. Push this folder to a GitHub repo
2. Go to https://vercel.com/new
3. Import the repo → Vercel auto-detects Vite settings → click **Deploy**

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
